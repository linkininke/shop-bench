# 商家工作台

这是一套对着岗位要求做的**个人演示项目**，不是虚构的在职经历。面试里就说：自己把搜索、推荐、广告、进销存和音频处理串成了一个能跑的小系统，可以打开代码讲。

岗位原文要的三块，都在这个目录里：

| 岗位 | 对应代码 |
|---|---|
| Java 做系统开发维护 | Spring Boot，`src/main/java` |
| 搜索 / 推荐 / 广告 | `search`、`reco`、`ads` |
| 音视频或 ERP | `media` 的 WAV 处理，`erp` 的进销存；视频转码命令在 `FfmpegRecipes` |
| C 语言 | `native/pcm_rms.c`，算法和 Java 的响度计算一致 |

## 运行

在项目目录执行：

```powershell
$env:HTTP_PROXY="http://127.0.0.1:7892"
$env:HTTPS_PROXY="http://127.0.0.1:7892"
$env:NO_PROXY="localhost,127.0.0.1"
mvn test
mvn spring-boot:run
```

浏览器打开 http://localhost:8088

数据在内存里，点「恢复初始数据」回到样本。重启程序也会回到样本。

## 五分钟怎么演示

1. 进销存：泽州铁器小刀库存 2。卖出 1 件后，顶部出现销售额和毛利。库存改成 9 再点「按盘点改」，流水里出现盘点。新品建档「山楂条」，再到搜索里能搜到，说明索引重建了。
2. 搜索「蜂蜜」。太行山蜂蜜是广告，下面是自然结果。页面下方的竞价表里，只有蜂蜜计划命中。
3. 搜索「醋」。苹果醋饮料赢。把晋城手工醋出价改成 8 元再搜，第一名换人。点「模拟点击扣费」，广告花费增加。暂停那条广告后再搜，它不再出现。
4. 推荐先看李强的「一起买过」，会出蜂蜜。再切「同一类目」，选赵磊，会出丝绸礼盒。两种推荐不是同一套公式。
5. 音视频：生成 440Hz，看波形、时长和响度。再试音量减半、裁到 0.4 秒、叠一层低音。视频只讲 FFmpeg 命令，不要说自己用 Java 解了 H.264。

讲稿在 `面试讲稿.md`。

## 怎么介绍才站得住

说「这是我按业务自己做的练习项目，商品、订单、广告都是样本数据」。不要说成在某公司负责过搜索广告三年。年限、是否上过生产，被追问时按事实说。讲得清楚实现，比编一段经历有用。

## C 代码

本机目前没有 gcc / MSVC。装好编译器后：

```powershell
gcc native/pcm_rms.c -o native/pcm_rms.exe -lm
```

Java 页面里先生成 WAV 并另存，再用这个程序读同一个文件，两边的 RMS 应该接近。面试时打开 `pcm_rms.c`，讲 RIFF 头、`fmt ` / `data` 块、16-bit 小端采样。
